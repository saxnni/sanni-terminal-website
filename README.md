# Portfolio Website

An interactive terminal-themed portfolio website built with HTML, CSS, and JavaScript. It features an interactive command-line interface, ASCII art header, animated glowing borders, and details about projects, skills, and background.

---

## ️ Available Commands

| Command    | Description                                       |
| :--------- | :------------------------------------------------ |
| `help`     | Displays a list of all available commands         |
| `whois`    | Brief introduction and bio about Sanni            |
| `skills`   | List of technical skills, languages, and tools    |
| `projects` | Highlights of recent software and course projects |
| `socials`  | Links to GitHub and social profiles               |
| `info`     | Contact information                               |
| `clear`    | Clears the terminal screen history                |

---

## ️ Built With

- **HTML5:** Semantic document structure
- **CSS3:** Modern CSS custom properties (`@property`), keyframe animations, conic gradients, and flexbox layout
- **JavaScript:** DOM manipulation, command parsing, and event handling

---

#  Sanni's Terminal Website

An interactive terminal-themed portfolio website built with vanilla HTML, CSS, and JavaScript. It features an interactive command-line interface, ASCII art header, animated glowing borders, and details about projects, skills, and background.

---

## Features

- **Interactive Command Prompt:** Type commands into the terminal emulator just like a real CLI.
- **Glowing Neon Aesthetic:** Custom animated `conic-gradient` border and dark neon color palette.
- **ASCII Art Banner:** Custom header banner welcoming visitors.
- **Click-to-Focus:** Automatically focuses the input field when clicking anywhere inside the terminal window.
- **Safe Command Handling:** Sanitized command echoing and clean output formatting.
- **Responsive & Lightweight:** Pure vanilla web technologies without external frameworks or dependencies.

---

## ️ Available Commands

| Command | Description |
| :--- | :--- |
| `help` | Displays a list of all available commands |
| `whois` | Brief introduction and bio about Sanni |
| `skills` | List of technical skills, languages, and tools |
| `projects` | Highlights of recent software and course projects |
| `socials` | Links to GitHub and social profiles |
| `info` | Contact information |
| `clear` | Clears the terminal screen history |

## ️ Built With

- **HTML5:** Semantic document structure
- **CSS3:** Modern CSS custom properties (`@property`), keyframe animations, conic gradients, and flexbox layout
- **JavaScript (Vanilla):** DOM manipulation, command parsing, and event handling
